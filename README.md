# PSUSphere

A web-based student information management system built for administrators to manage and monitor student data, organizations, and academic programs.

## Overview

PSUSphere provides an admin interface where authenticated users can view and manage comprehensive student records. The dashboard gives a quick snapshot of key metrics — total students, new enrollees this year, active organizations, and registered programs.

## Features

- **Dashboard** — A summary panel displaying four key metrics:
  - **Total Students** — The overall number of students currently enrolled in the system.
  - **Joined This Year** — The number of students who enrolled within the current year.
  - **Organizations** — The total number of active student organizations.
  - **Programs** — The total number of academic programs offered across all colleges.

- **CRUD Operations** — Create, read, update, and delete records across all entities (Students, Colleges, Programs, Organizations, and Org Members).
  Administrators have full control over all data — add new records, view existing ones, make updates, or remove outdated entries as needed.

- **Search** — Filter and find records quickly across all modules.
  Speeds up data retrieval by allowing administrators to look up specific students, organizations, or programs without manually scrolling through lists.

- **Sorting** — Sort organization members by relevant fields.
  Helps administrators organize and review member lists in a structured order, making it easier to analyze or compare data.

## Modules

| Module | Description |
|---|---|
| Students | Manage student profiles and information |
| Colleges | Track college units within the institution |
| Programs | Manage academic programs per college |
| Organizations | Manage student organizations |
| Org Members | Track student membership in organizations |
